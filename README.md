# Фондовая биржа — план проекта

## Описание проекта

Веб-приложение «Фондовая биржа» предназначено для отображения движения валют и криптовалют в режиме реального времени. Приложение реализует курсы обмена (доллар, рубль, юань), а также котировки двух и более криптовалют. Пользователь может отслеживать динамику курсов, конвертировать валюты и просматривать историю изменений.

---

## Архитектура приложения

Приложение строится по клиент-серверной архитектуре:

- **Клиентская часть** — интерактивный интерфейс для работы с котировками, графиками и конвертером валют.
- **Серверная часть** — API-сервер, агрегирующий данные из внешних источников (биржевые и крипто-API), хранящий историю и управляющий сессиями пользователей.

---

## Модули клиентской части

### Пользовательский интерфейс
Клиентская часть предоставляет интуитивно понятный интерфейс для работы с биржевыми данными. Интерфейс включает:
- панель с актуальными котировками (USD, RUB, CNY и криптовалюты),
- интерактивные графики движения курсов,
- конвертер валют с мгновенным пересчётом.

### Модуль отображения котировок
Основной модуль отображает текущие курсы всех поддерживаемых валют и криптовалют. Данные обновляются в реальном времени или с заданным интервалом. Курсы отображаются с указанием процентного изменения за день и цветовой индикацией (рост/падение).

### Модуль графиков и визуализации
Модуль строит интерактивные графики движения курсов за выбранный период (1 час, 1 день, 1 неделя, 1 месяц, 1 год). Поддерживаются линейный и свечной типы графиков. Пользователь может масштабировать и прокручивать график, а также сравнивать несколько валют одновременно.

### Модуль конвертера валют
Позволяет пользователю быстро рассчитать сумму обмена между любыми поддерживаемыми валютами. При вводе суммы результат пересчитывается мгновенно с использованием актуального курса. Поддерживается обмен как между фиатными валютами, так и между фиатными и криптовалютами.

### Модуль истории и аналитики
Пользователь имеет доступ к истории изменений курсов за произвольный период. История представлена в виде таблицы и графика с возможностью поиска и фильтрации по валюте и дате. Дополнительно отображается минимальное и максимальное значение курса за выбранный период.

### Модуль уведомлений
Пользователь может настроить оповещения при достижении курсом заданного значения (например, «уведомить, когда USD/RUB превысит 95»). Уведомления приходят в браузер или на e-mail.

### Модуль поддержки адаптивного дизайна
Интерфейс оптимизирован для различных устройств: веб-браузер, мобильный браузер, планшет. Реализованы адаптивные стили, поддержка сенсорных жестов (масштабирование графика, прокрутка), компактный вид котировок для малых экранов.

### Модуль оптимизации
Для обеспечения мгновенного отклика применяются:
- кэширование последних полученных котировок,
- оптимизация сетевых запросов (WebSocket для потоковых данных),
- ленивая загрузка исторических данных при прокрутке графика.

## Модули серверной части

### Модуль агрегации данных
Серверная часть подключается к внешним API (например, ExchangeRate API, CoinGecko, Binance API) для получения актуальных котировок фиатных валют и криптовалют. Данные нормализуются в единый формат и передаются клиенту.

### Модуль хранения истории
Все полученные котировки сохраняются в базе данных с временными метками. Это позволяет строить графики за любой исторический период и проводить аналитику без обращения к внешним источникам.

### Модуль аутентификации и пользовательских настроек
Пользователи могут регистрироваться и авторизоваться, чтобы сохранять персональные настройки: избранные валюты, пороговые значения для уведомлений, предпочитаемый период графика.

### Модуль определения валюты по геолокации
Сервер определяет регион пользователя и автоматически выставляет приоритетную валюту на главной странице (например, для пользователей из России приоритет у RUB).

### Модуль API и безопасности
Серверная часть предоставляет REST API для клиента. Все запросы проходят валидацию. Реализована защита от злоупотреблений (rate limiting), а ключи внешних API хранятся только на сервере.
