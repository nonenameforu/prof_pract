Виды документации

В рамках проекта разработано несколько видов документации для разных аудиторий.

📖
DocBook XML
Структурированная техническая документация в формате DocBook 5.0. Все модули, классы, методы и свойства с таблицами.
🌐
DocFX HTML
Автоматически сгенерированное справочное руководство программиста из XML-докблоков C# через инструмент DocFX.
📦
CHM Help
Пользовательская документация в формате Compiled HTML Help. Создана в HTML Help Workshop с деревом навигации.
